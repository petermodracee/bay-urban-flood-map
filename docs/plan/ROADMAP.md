## Backlog / Future TODOs
- **High-resolution SF pass (`10 m` grid / `1 m` subgrid):** Re-run full SF once v0.2 `20 m / 2 m` validation and drainage-lock deltas are verified.
- **Automated CI:** GitHub Actions workflow running `pytest`, `ruff check && ruff format --check`, `node --test`, `npm run lint`, and `npm run build` on pull requests.
- **Viewer UX enhancements (`v0.7+`):** Neighborhood summary stats panel and SFEI shoreline/levee crest overlay toggle (address/intersection search, hotspot chips, and shareable URL state shipped in `v0.6` Phase 1).
- **Caltrans PeMS / 511 SF Bay Tier C provider (`v0.6`/`v0.7`):** Add a pluggable **Caltrans PeMS historical CHP incident CSV** (and/or 511 SF Bay) Tier C provider once the PeMS portal upgrade completes, for Bay-wide highway closure validation alongside the existing SF DataSF emergency-dispatch provider.
- **Climate-adjusted rainfall sensitivity:** Optional future-precipitation multiplier experiments once historical baseline is published.
- **Experimental 48-hr forward flood forecasting (`v0.8+`):** Swap MRMS QPE for **NOAA HRRR** (`3 km`, 0–48 hr) or **NBM** (`2.5 km`, 1–7 days; 50th/90th percentile QPF uncertainty bands) via the existing `netamprfile` pipeline, paired with **NOAA CO-OPS predicted tides / SFBOFS storm surge** and 5-day prior MRMS antecedent soil moisture (`AMC-III` / `wet` CN) for scheduled pre-storm street-ponding outlooks (explicitly framed as experimental screening, not official NWS warnings).
- **North Bay & Delta River Basins (`v1.1+ / v2.0`):** Expand beyond the `v1.0` Urban Bay Core to Napa, Sonoma, Solano, and East Contra Costa, adding upstream fluvial discharge boundary conditions (`sfincs.dis`) and Delta levee inventories.
- **Contributor "How-To" Run Guide:** step-by-step walkthrough to set up `conda-forge` + Docker (`deltares/sfincs-cpu`), fetch/place manual inputs (e.g., SFEI Bay Shore Inventory), run `00_fetch_data.py` through `04_export_cog.py`, and preview exported COGs locally in `web/`. *(Note: the plain-English **About** and **Technical Methodology** pages were added in `v0.6` Phase 4: `web/about.html` and `web/methodology.html`.)*
- **Groundwater rise under SLR (`v0.8+`):** Account for shallow water tables reducing soil infiltration capacity (SCS Curve Number) and infiltrating combined sewers, which reduces effective drainage capacity under sea level rise (Befus et al., 2020, `doi:10.1038/s41558-020-0874-1`; Plane et al., 2019, `doi:10.3390/w11112228`; Bosserelle et al., 2022, `doi:10.1029/2021EF002580`).
- **Land subsidence & vertical land motion (`v0.8+`):** Apply InSAR-based vertical land motion (VLM) adjustments to the DEM or local SLR offsets rather than treating sea level rise as a spatially uniform offset (Shirzaei & Bürgmann, 2018, `doi:10.1126/sciadv.aap9234`; Govorčin et al., 2025, `doi:10.1126/sciadv.ads8163`).
- **Joint rain–surge probability for design scenarios (`v0.7+`):** Replace the current coincident-stress design assumption (design rainfall coinciding with MHHW + 0.35 m surge) with empirically estimated joint rain–surge return periods from Bay records (Wahl et al., 2015, `doi:10.1038/nclimate2736`; Moftakhari et al., 2017, `doi:10.1073/pnas.1620325114`; Gori & Lin, 2022, `doi:10.1029/2022EF003097`).
- **Outfall & wastewater treatment capacity under SLR (`v0.8+`):** Model coastal combined-sewer outfall and treatment capacity constraints under rising tailwater, linked to the Tier 1b tide-locking formulation (Hummel et al., 2018, `doi:10.1002/2017EF000805`).

## Release Convention
Each completed milestone is tagged on `main` using clean SemVer (`v0.x.0`, marked `--prerelease` on GitHub until `v1.0.0`, no tag suffix) targeting the milestone's final merge commit, with release notes summarizing key validation metrics and linking the milestone plan and report:
```bash
gh release create v0.x.0 --target <merge_commit_sha> --prerelease --title "v0.x.0 — <Milestone Title>"
```
